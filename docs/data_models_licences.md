# Data, models and licences

Everything this project uses that it did not create, with its licence, where it comes from and where it is used; and
every model the project trains, with the notebook or script that trains it, the data it needs, where the pipeline
expects it and what its licence would be if it were shared. **No dataset and no model weights are stored in this
repository**: they are downloaded or trained by each user.

*This is a record of the licences stated by each source, not legal advice. Whether the licence of a training set
carries over to the weights trained on it is not settled; the conservative reading is used below.*

## 6 · Personal data and secrets

The notebooks have no saved outputs and no keys. Google Drive is mounted with `drive.mount`, which asks **each user** to
sign in and mounts **their own** Drive (`MyDrive/hooptrack/` is relative to whoever runs the notebook). The only API key
(Roboflow, optional) is read from the user's own Colab secret `ROBOFLOW_API_KEY` or environment variable.
